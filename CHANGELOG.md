# Changelog

## 0.1.1 — 2026-08-17

First public preview release.

- Embed the official DeepSeek Harness conversation, trajectory, tool, subagent, Session log and settings components in Obsidian.
- Bind multiple DSH Sessions to individual Obsidian files or folders.
- Add an Obsidian-style standalone AI Workbench with collapsible Session groups.
- Let users choose a default DSH Workspace for newly created standalone Sessions.
- Keep official DSH settings accessible before a conversation header exists.
- Repair narrow-pane settings typography while preserving official light-theme tokens.
- Use only the main local DSH instance on port 3080; remove retired 3081/3099 runtime paths.
- Preserve plugin `data.json` during test-vault upgrades.
- Publish a portable dependency lock, Windows installation guide and three-platform CI.
